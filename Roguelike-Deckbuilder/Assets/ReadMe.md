
# SlayTheSpire-Like

基于 Unity 2022.3 的 Roguelike 卡牌游戏项目，正在持续开发中。

## 技术栈

- Unity 2022.3 / UniTask / YooAsset / DOTween / UGUI

## 已实现的功能

### 架构设计

- MVP + ServiceLocator + EventBus + 流程状态机，用于 UI 和业务逻辑的解耦
- UIService 统一管理 UI 的打开、关闭和生命周期

### 地图系统

- 基于配置表驱动的地图生成
- 支持多行多列节点布局，节点类型根据权重随机分配
- 节点点击后解锁相邻节点，并触发对应事件

### 战斗系统

- 回合制战斗流程（玩家回合 → 敌人回合）
- 手牌管理：抽牌、打牌、费用消耗
- 卡牌效果：伤害、格挡、Buff 等基础类型
- 敌人 AI：支持不同敌人配置不同的行为逻辑

### 配置与数据

- 卡牌、敌人、地图等配置通过 Excel 导表生成 C# 数据类
- 运行时通过 ConfigService 读取，与业务逻辑分离

### 资源管理

- YooAsset 异步加载预制体，图片资源，Excel配置表等。
- 对象池复用 UI 列表项（卡牌、地图节点等）

## 当前进度

- 地图探索流程基本可用
- 战斗系统核心循环已跑通
- 商店、休息节点已接入
- 存档系统支持保存和读取进度
